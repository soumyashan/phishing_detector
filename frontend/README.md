## 🚀 Welcome to the Project & Capability Hub
This platform serves as the central command console, architectural implementation, interactive simulator, and team coordination hub for **Smart India Hackathon (SIH 2026) Problem Statement 26106**.

### 🌟 Core Philosophy
> **"We do not just detect the email. We investigate it."**
Traditional spam/phishing filters output a binary label (*Phishing* or *Spam*). 
Our platform provides a complete **Forensic Intelligence Lifecycle**:
1. **Cryptographic Header Verification**: RFC-compliant SPF, DKIM, and DMARC alignment analysis.
2. **Relay Hop Trace Engine**: Deconstructs `Received:` headers to map the exact hop-by-hop transmission route from source to destination.
3. **Infrastructure Geolocation & Attribution Support**: Pinpoints probable origin server ASNs, hosting providers, and coordinates with honest confidence scoring (High / Medium / Low).
4. **Explainable AI / NLP Threat Scoring**: Multi-signal scoring that highlights urgency, credential harvesting, authority impersonation, and lookalike domains.
5. **Campaign Correlation Graph**: Discovers shared threat infrastructure (IPs, MX servers, domain clusters) across multiple phishing emails.
6. **Automated Forensic Dossier**: Generates audit-ready reports with SHA-256 evidence hashing for cybersecurity investigators and law enforcement.
